# Как вернуть свои режимы

Из коробки Cube Remote знает только 4 режима базового тарифа. Режимы из вашей
подписки (расширенной, «Экстра» и т.д.) добавляются так: вы один раз запускаете
режим из **официального** приложения, а клиент узнаёт его номер. Так у каждого
оказываются ровно те режимы, к которым у него есть доступ.

Понадобится, чтобы официальное приложение хотя бы раз заработало (например, днём,
когда сервер жив). Номер режима не меняется — узнать его нужно один раз.

## Способ 1. Режим обучения в Cube Remote (проще всего)

1. Запустите нужный режим из официального приложения `deep up`, как обычно.
2. Отпустите кубик: закройте `deep up` на телефоне (смахните из списка приложений)
   или выключите на телефоне Bluetooth. Программа на кубике продолжит играть —
   телефон ей не нужен.
3. Откройте Cube Remote. Он подключится и увидит, что играет незнакомый режим:
   появится карточка «На кубике играет режим #N, которого нет в списке».
4. Введите название, как оно называется в приложении, и нажмите «Сохранить».

Режим появится в сетке. Убрать его — «×» при наведении. Повторите для каждого
своего режима.

## Способ 2. nRF Connect (любой телефон, без Mac)

1. Запустите режим из `deep up`, затем закройте `deep up`.
2. В **nRF Connect** подключитесь к `deep.r` / `deep.n`.
3. Сервис `98658F38-…`, характеристика `98658F39-…` → «читать».
4. Второй байт пакета — номер режима (hex). Например, `AA 0A 7F …` → режим `0x0A` = 10.

Дальше этот номер можно использовать в любом клиенте (см. [PROTOCOL.md](PROTOCOL.md)).

## Способ 3. Подсмотреть команду официального приложения

Если хочется увидеть сам пакет, который отправляет `deep up`:

**Android** — журнал Bluetooth HCI:

1. Настройки → «Для разработчиков» → включить «Журнал Bluetooth HCI».
2. Выключить и включить Bluetooth, запустить режим из `deep up`.
3. Забрать журнал (`adb bugreport` → `FS/data/log/bt/btsnoop_hci.log`)
   и открыть в Wireshark. Фильтр: `btatt.opcode == 0x12`.

**iPhone** — PacketLogger:

1. Установить профиль Bluetooth-логирования с developer.apple.com
   (раздел Profiles and Logs → Bluetooth), перезагрузить телефон.
2. На Mac: Xcode → Additional Tools → **PacketLogger**, подключить iPhone кабелем,
   File → New iOS Trace.
3. Запустить режим из `deep up` и найти запись (ATT Write Request) в характеристику
   `98658F3A-…`.

В обоих случаях вы увидите 8 байт вида `1A 0A 7F 01 80 70 00 00`:
второй байт (`0A` = 10) — номер режима, последние четыре — длительность в секундах.

## Чего здесь нет

Таблицы номеров платных режимов. Технически кубик не проверяет подписку, но
этот проект не публикует то, за что другие пользователи платят. Если режим
вам нужен — оформите подписку у производителя.
