# Cube Remote

Неофициальный клиент для **кубика сна deep** (deep·r / deep·n): запуск и остановка
программ сна по Bluetooth прямо с Mac, без аккаунта, без интернета и без серверов
производителя.

> Проект не связан с производителем кубика (ООО «ЦНСиБ», бренд deep) и не одобрен им.
> «deep» — товарный знак его владельца; здесь он используется только для того, чтобы
> было понятно, с каким устройством работает клиент.

---

## Почему этот проект существует

Я пользуюсь кубиком deep больше двух лет, более того, на протяжении всего использования кубика я плачу за подписку для дополнительных режимов.

Сам кубик — отличное устройство, которое реально работает, я подарил его друзьям, сам использую каждый день и беру в поездки. Мой сон стал сильно лучше благодаря кубику, за это производителю я выражаю огромную человеческую благодарность.

Однако всё время, пока я пользуюсь кубиком, приложение от производителя вызывает у меня исключительно негативные эмоции. Когда я хочу включить кубик и лечь спать, у ребят лежит бэкенд, меня выкидывает из аккаунта и нужно перезаходить. После любого обновления вместо корректного уведомления тебя просто выбрасывает из аккаунта и не дает авторизоваться заново, остается только гадать, что на этот раз — сломался бэкенд или вышла обнова. Не считая того, что даже в обычные дни, когда все работает, приложение очень долго ищет кубик и иногда требуется несколько раз его выключить-включить, чтобы все заработало.

В итоге я остаюсь с технически классным устройством, которое не могу запустить, потому что приложение в очередной раз тупо не работает. Надо ли говорить, какие эмоции у меня это вызывает.

С аналогичной проблемой сталкиваюсь не только я, а еще и мои друзья и другие люди, с которыми я обсуждал кубик.

И это не только мое мнение: на момент публикации репозитория (октябрь 2026) у `deep up`
средняя оценка 2,4 из 5 (227 оценок) в российском App Store и 2,0 из 5 в
международном. Люди массово жалуются на то, что приложение не работает, и, казалось бы, за два с лишним года его можно было бы полностью переработать.

Вместо этого стандартный ответ разработчика на жалобы с одной звездой —
«Спасибо, что воспользовались нашим сервисом». Это не тот уровень отношения к своим клиентам, которого ожидаешь, когда платишь за устройство почти 30 тысяч рублей, как заплатил я.

При этом для того, чтобы кубик заработал, сервер не нужен вообще: программы зашиты в прошивку, а команда «запусти программу N до 7:30» — это 8 байт по Bluetooth.
Поэтому я написал этот клиент для своего кубика — и выкладываю, чтобы другим
владельцам не пришлось проходить через то же самое.

Я имею полное право использовать свое собственное устройство, за которое заплатил, вне зависимости от того, работает ли официальное приложение. Такое же право имеют и другие пользователи кубика, поэтому я опубликовал это приложение.

**Я не ищу конфликта с производителем.** Если в какой-то момент официальное приложение станет
работать надежно — я с радостью заархивирую этот репозиторий и продолжу использование продукта, за который заплатил. Если вы представляете
производителя и хотите что-то обсудить — откройте issue, я отвечу.

## Чего этот проект НЕ делает

- **Не открывает платные режимы.** Я не поддерживаю пиратство. Поэтому из коробки в этом репозитории доступны только 4 режима базового
  тарифа. Если у вас есть действующая подписка, другие режимы вы можете добавить сами, «научив» клиент: запускаете
  режим из официального приложения, Cube Remote видит его номер и запоминает.
  См. [docs/RECOVER_YOUR_PROGRAMS.md](docs/RECOVER_YOUR_PROGRAMS.md).
  Я не продаю подписки, они по-прежнему оформляются в личном кабинете у производителя.
- **Не трогает прошивку.** Сервис обновления прошивки (TI OAD) не используется
  ни в приложении, ни в скриптах. Окирпичить кубик этим софтом нельзя.
- **Не ходит в интернет.** Никакой телеметрии, никаких аккаунтов.
- **Не содержит кода, графики или текстов производителя.** Иконки и весь код — свои.

## Что умеет

- Живёт в трее (строке меню) с иконкой кубика; по клику — панель управления.
- Сам находит кубик и держит соединение; после обрыва (ушли из дома, Mac уснул)
  переподключается в фоне. Открыли панель — статус уже там, ждать не нужно.
- Состояние в реальном времени: играет / пауза, какой режим, прогресс, сколько
  осталось и до скольки. Заряд и индикатор зарядки.
- Время задаётся как в официальном приложении — **временем подъёма**;
  длительность считается сама (кубик принимает от 1 до 24 часов).
- Мощность: мин / средняя / макс.
- «Отдать кубик телефону» — Mac отключается и не мешает официальному приложению
  (кубик держит только одно соединение).

## Установка (macOS 11+)

1. Скачайте `Cube Remote.app` со страницы [Releases](../../releases).
2. Сборка не подписана сертификатом Apple, поэтому при первом запуске:
   правый клик → «Открыть» → «Открыть». Или в терминале:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Cube Remote.app"
   ```
3. Разрешите доступ к Bluetooth, когда macOS спросит.
4. Если кубик сейчас подключён к телефону — закройте `deep up` на телефоне.

Сборки собираются в GitHub Actions из этого репозитория
([.github/workflows/release.yml](.github/workflows/release.yml)) — можно проверить,
что внутри ровно этот код.

### Сборка из исходников

Нужны Rust (stable) и Node.js 18+.

```bash
cd app
npm install
npx tauri build
```

## Другие устройства

Mac-приложение — лишь один из вариантов. Протокол простой, его можно реализовать
на чём угодно, где есть Bluetooth LE: Python, Android, iOS (CoreBluetooth),
ESP32, Home Assistant, веб-страница на Web Bluetooth (Chrome на Android и десктопе;
на iPhone — в браузере Bluefy, Safari Web Bluetooth не поддерживает).

- [docs/PROTOCOL.md](docs/PROTOCOL.md) — полное описание протокола.
- [tools/deep_probe.py](tools/deep_probe.py) — консольный скрипт на Python
  (`pip install bleak`): найти кубик, посмотреть состояние, запустить и остановить
  программу.

## Отказ от ответственности

Софт распространяется «как есть», без гарантий (см. [LICENSE](LICENSE)).
Используйте на свой риск. Кубик — устройство, влияющее на сон; параметры работы
(длительность, мощность) ограничивает его собственная прошивка, этот клиент
не позволяет выйти за её пределы.
